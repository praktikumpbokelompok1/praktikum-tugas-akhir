# Catch Falling Object

**Catch Falling Object** adalah game arcade sederhana berbasis Python dan Tkinter yang menerapkan konsep Object-Oriented Programming (OOP). Pemain mengendalikan sebuah keranjang untuk menangkap benda-benda yang jatuh dari atas layar sambil menghindari sampah yang dapat mengurangi nyawa dan skor.

## Fitur

* Dibangun menggunakan Python dan Tkinter
* Menerapkan konsep OOP (Object-Oriented Programming)
* Tampilan bergaya pixel hitam-putih
* Pilihan tingkat kesulitan Easy dan Hard
* Sistem skor dan nyawa
* Fitur pause dan resume permainan
* Tema Dark Mode dan Light Mode
* Deteksi tabrakan objek dengan keranjang
* Menu utama dan pengaturan

## Cara Bermain

Pemain menggerakkan keranjang ke kiri dan kanan untuk menangkap benda yang jatuh dari atas layar.

Benda yang dapat ditangkap antara lain:

* Pensil (+10 poin)
* Penghapus (+15 poin)
* Buku (+20 poin)
* Penggaris (+25 poin)

Selain itu terdapat sampah yang harus dihindari. Jika sampah tertangkap, skor akan berkurang dan pemain kehilangan satu nyawa.

Permainan berakhir ketika:

* Pemain berhasil mencapai skor target 300 poin (Menang)
* Nyawa pemain habis (Kalah)

## Kontrol

* Tombol **Panah Kiri** atau **A** untuk bergerak ke kiri
* Tombol **Panah Kanan** atau **D** untuk bergerak ke kanan
* Tombol **P** untuk Pause atau Resume
* Klik mouse untuk memilih menu

## Tingkat Kesulitan

### Easy

* Memiliki 5 nyawa
* Kecepatan objek lebih lambat
* Kemunculan sampah lebih sedikit

### Hard

* Memiliki 3 nyawa
* Kecepatan objek lebih cepat
* Kemunculan sampah lebih sering
